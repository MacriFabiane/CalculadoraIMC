## 📝 Descrição  

Este projeto é uma aplicação web desenvolvida em **Python** com o framework **Django** que permite calcular o Índice de Massa Corporal (IMC) de um usuário. A aplicação está configurada para ser hospedada na **Vercel**, proporcionando uma experiência simples e acessível para demonstração.  

---

## 🚀 Funcionalidades  

- Entrada de peso e altura para cálculo do IMC.  
- Exibição do resultado do IMC com uma classificação (ex: abaixo do peso, normal, sobrepeso, etc.).  
- Interface amigável e responsiva.  
- Deploy na Vercel com suporte a rotas dinâmicas do Django.  

---

## 🛠️ Tecnologias Utilizadas  

- **Linguagem:** Python  
- **Framework:** Django  
- **Deploy:** Vercel
